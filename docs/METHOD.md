# 方法设计与实验协议

## 1. 目标

以一个固定类别的正常样本为训练数据，判断新图像是否偏离正常分布，并定位疑似区域。异常标签与掩码仅在评测阶段使用。ResNet 参数被冻结，所谓“训练”是正常分布与记忆库拟合，不是反向传播训练 backbone。

## 2. 四份数据的职责

| 划分 | 用途 | 是否允许参与记忆库 |
|---|---|---|
| train / good | 特征均值方差、空间统计、门控、记忆库、可选光照模板 | 是 |
| tune / good | 两分支分数尺度、候选像素阈值 | 否 |
| calibration / good | 各策略的图像分数排序校准 | 否 |
| test | 只报告性能 | 否 |

为什么 tune 和 calibration 分开：若用 calibration 同时选择分数函数，再对同一数据声称标准 split conformal 保证，论证会失去前提。这里先用 train/tune 固定分数函数，再进行独立排序校准。

评测前输出 splits.json，记录相对路径与每张文件 SHA-256；不同划分存在相同文件内容时直接报错。该检查不等同于检测近重复图片，真实连拍数据仍应按工件/批次隔离。

## 3. 特征

轻量版把 96×96 RGB 图像分为 16×16 网格，每格输出 14 维：RGB 均值 3、标准差 3、灰度横纵梯度均值 2、3×3 网格邻域 RGB 均值 3、本格与邻域 RGB 均值之差 3。

深度版使用 torchvision 官方 ImageNet ResNet18，提取 layer1 的 64 通道与 layer2 的 128 通道，对齐网格并拼接为 192 维。输入直接整图缩放，沿用 ImageNet 通道标准化。没有使用分类默认的中心裁剪，以免裁掉边缘缺陷；它也因此不同于官方分类评测预处理。

逐通道使用 train 的均值与标准差进行 z-score，标准差下界 0.015，避免低变化维度放大数值噪声。

## 4. 全局记忆库

从训练 patch 中最多随机抽取 4096 个候选，用贪心最远点选择 M 个原型：每次选择距已选集合最近距离最大的候选。默认 M=128，真实深度实验 M=256。空间复杂度受候选池和记忆库控制，并不是全数据精确 k-center 最优解。

对查询 z，全局异常分数：

g(z) = min(m in memory) sqrt(mean((z-m)^2))

保存原型所属正常图片与网格坐标，用于显示最近正常证据。最近邻是欧氏匹配证据，不是缺陷原因推理。

## 5. 空间分支与可靠性权重

每个网格位置 u 拟合正常特征均值 μu 与标准差 σu（下界 0.20）：

s(u) = sqrt(mean(((z(u)-μu)/σu)^2))

这是对角标准化距离，不是完整协方差 Mahalanobis 模型。独立维度假设可以降低内存，但丢失相关性信息。

令 vu = median_channel(σu)，r = median_location(vu)，则：

w(u) = clip(r / (r+vu), 0.2, 0.8)

正常变化较大的位置降低空间分支权重。训练数据过于规则或方差被下界截断时，w 会接近或等于 0.5；此时门控退化为等权融合，不能宣称仍有独立收益。

在 tune 正常图上分别取 g 和 s 的全图 95% 分位数归一化，得到 G 和 S。四个消融策略：

- global: G
- spatial: S
- fusion: 0.5G + 0.5S
- gated: (1-w)G + wS

注意：目前 predict 为便于统一解释仍计算两个分支，即使选择单分支模式也如此；耗时不能解释成纯分支实现的成本。

## 6. 图像聚合和校准

图像分数取最高 2% patch 的平均值，避免仅靠最大值对单点噪声过敏，也避免全图均值稀释小缺陷。该超参数预先固定，未利用测试标签搜索最优值。

对 n 个正常 calibration 分数 ci，新图分数 t：

p(t) = (1 + count(ci >= t)) / (n+1)

当 p <= alpha 时标为疑似异常，默认 alpha=0.05。重复分数采用 >=，保守处理 ties。UI 同时显示第 ceil((n+1)(1-alpha)) 个排序阈值；判定以 p 值为准。校准图过少时阈值可能无穷大，JSON 显示 null，无法在该 alpha 下拒绝正常假设。

在固定分数函数、正常校准样本与未来正常样本可交换等前提下，这提供正常样本误报的边际控制；**不是每个类别子群或每个批次都保证 5%，更不保证有限测试集实测 FPR 一定低于 5%**。对光照/设备变化的数据不能直接沿用保证。

## 7. 候选区域

在 tune 正常像素网格分数上固定 99.5% 分位阈值，二值化 patch 并最近邻放大。热力图使用固定阈值参考色标，避免每张图各自 min-max 后正常图也全红。

图像分数与像素阈值用途不同，图像正常但存在少量候选区域是可能的。像素阈值没有像素级 conformal 保证，patch 之间也不独立。

AUROC 使用双线性放大的连续图，IoU 使用最近邻放大的二值网格。真值使用最近邻缩放。像素 AUROC、IoU 都报告在模型分辨率下，不是原分辨率 MVTec 标准排行榜协议。

## 8. 鲁棒光照校正

train 图像逐像素中位数作为正常模板。对输入与模板的差值，用 [1,x,y] 为基函数拟合每个 RGB 通道的低频平面；4 轮 IRLS 下调较大残差权重，以减少局部缺陷污染。校正幅度逐通道限制在 ±0.25，输出裁剪至 [0,1]。

这是一种拍摄条件稳定、图像大致对齐时的启发式。大面积异常可能被部分吸收，错位物体也可能扭曲拟合，因此有明确开关并单独消融。不能将合成平面光照上的改进推广为对任意真实光照鲁棒。

光照模块是在第一轮合成压力测试发现误报后加入的，因此合成生成机制已参与开发，不是完全盲测；多随机种子只检查该生成机制下的稳定性。真实 bottle 结果没有用于调节超参数。

## 9. 复杂度与改进方向

记忆库查询 O(PMD)，P 为 patch 数、M 为记忆容量、D 为维度。当前实现分块矩阵距离，适合小型 CPU 演示。更大数据可评估随机投影、FAISS 或 GPU 索引，但本项目没有声称已经实现。

下一步应优先扩大真实类别、引入严格外部验证集、做输入分辨率/记忆容量与资源预算对比，再考虑更强 backbone。不要根据现有测试集反复调参数后继续把它当未见测试集。
