# Third-party references and assets

The project's own source code is under MIT. This does not relicense dependencies, pretrained weights or datasets.

- NumPy: numerical operations, BSD-3-Clause.
- Pillow: image I/O and rendering, HPND-style Pillow license; see installed package metadata.
- PyTorch and torchvision: frozen pretrained ResNet18, respective upstream licenses. The pretrained weights are not included in the repository; the official torchvision downloader retrieves them into the local cache.
- pytest: development tests, MIT.
- MVTec AD bottle: MVTec Software GmbH, CC BY-NC-SA 4.0. Official source: https://www.mvtec.com/research-teaching/datasets/mvtec-ad . Data and derived image galleries are kept in ignored data/ and runs/ folders, not included in the public code package.
- Published gallery docs/assets/synthetic-gallery.png is generated by this project's procedural generator and includes only synthetic imagery.
- Method references are listed in docs/ORIGINALITY.md. Reference to a paper is not a claim of reproducing its full method or benchmark.

No third-party anomaly-detection repository source was copied. Inspect license terms of any additional datasets before distributing them.
